# مدير الديون الذكي برو SMS (Smart Debt Manager Pro SMS)

تطبيق أندرويد احترافي يعمل **بالكامل دون إنترنت** لإدارة العملاء والديون والمدفوعات والحوالات والرسائل النصية (SMS)، مع نظام متقدم لاستيراد قواعد بيانات تطبيقات المحاسبة العربية مثل **(دفتر الحسابات)** و**(المحاسب الذكي برو)**.

---

## المزايا الرئيسية

1. **النظام المحاسبي الدقيق (Room SQLite محلي)**:
   - المعادلة المحاسبية المعتمدة: `الرصيد = إجمالي الديون - إجمالي المدفوعات`.
   - حساب الأرصدة التلقائي والفوري في لوحة التحكم وكشوفات الحساب.
   - منع العمليات السالبة والصفرية.
   - منع العمليات المكررة ومنع الدفع الزائد افتراضياً (مع خيار تحكم من الإعدادات).
   - دعم الأرصدة الافتتاحية والتسويات.
   - عدم حذف العمليات المعتمدة نهائياً؛ بل عكسها مع تسجيل السبب في **سجل المراجعة (AuditLog)**.

2. **الواجهات الـ 18 المتكاملة (Jetpack Compose + Material 3 + RTL عربي بالكامل)**:
   1. الرئيسية والإحصائيات (لوحة تحكم ورسوم بيانية تفاعلية).
   2. إدارة العملاء (بحث، تصفية، تصنيف مدين/مسدد/متأخر/مؤرشف).
   3. إضافة وتعديل العملاء.
   4. تفاصيل العميل.
   5. كشف الحساب مع الرصيد التراكمي وتصدير Excel / CSV.
   6. إضافة دين / رصيد افتتاحي.
   7. تسجيل دفعة / تسوية.
   8. سجل العمليات وسجل التعديلات والمراجعة.
   9. التذكيرات والمتأخرات (مع دعم WorkManager محلياً).
   10. الحوالات الواردة (النجم، الامتياز إكسبرس، داديه، الأكوع موني، إتش بي) مع منع تكرار المرجع وتأكيد التحويل لدفعة.
   11. رسائل SMS (معاينة وتعديل، تحديد المدينين/المتأخرين، إرسال عبر `ACTION_SENDTO` دون `SEND_SMS` أو إرسال صامت، وتأكيد يدوي لحالة الإرسال).
   12. قوالب الرسائل (تدعم المتغيرات الـ 8: `{اسم_العميل}`، `{الرصيد}`، `{إجمالي_الديون}`، `{إجمالي_المدفوعات}`، `{التاريخ}`، `{اسم_المتجر}`، `{رقم_التواصل}`، `{رقم_الحساب}`).
   13. التقارير والتحليلات المالية.
   14. استيراد البيانات (`.db`, `.sqlite`, `.sqlite3`, `.csv`, `.xls`, `.xlsx`, `.json`, والنسخ الاحتياطية) مع المعاينة ومطابقة الأعمدة واكتشاف التكرار ونسخة الأمان التلقائية قبل الاستيراد.
   15. تصدير البيانات (XLSX حقيقي، CSV متوافق مع العربية UTF-8 BOM، JSON).
   16. النسخ الاحتياطي والاستعادة (`SmartDebtManager-backup.json`) مع فحص بصمة التحقق `SHA-256`.
   17. الإعدادات والمظهر (الوضع الفاتح والداكن + الثيم الرسمي الأزرق والفيروزي + ثيم أحمر وأبيض اختياري).
   18. المساعد الذكي المحلي (تحليل مالي ذكي يعمل دون إنترنت 100%).

---

## الخصوصية والأمان

- **لا يوجد تسجيل دخول أو حسابات.**
- **لا يوجد أي اتصال بالإنترنت أو رفع بيانات العملاء إلى السحابة.**
- **عدم طلب صلاحية `SEND_SMS` افتراضياً**؛ يتم فتح تطبيق الرسائل الرسمي عبر Android Intent وبإرادة المستخدم.
- قراءة قواعد البيانات المستوردة بوضع **القراءة فقط (`OPEN_READONLY`)** على نسخة مؤقتة دون المساس بالملف الأصلي.

## البناء والتشغيل

- **Package Name:** `com.smartdebt.app`
- **APK Name:** `SmartDebtManagerProSMS.apk`
- **الأدوات:** Kotlin, Jetpack Compose, Material 3, Room Database, Navigation Compose, DataStore Preferences, WorkManager, Storage Access Framework (SAF).
- لبناء التطبيق عبر Gradle:
  ```bash
  gradle :app:assembleDebug
  ```
- لتشغيل الاختبارات المحلية (Robolectric + Room):
  ```bash
  gradle :app:testDebugUnitTest
  ```
